# Markdown Quick Guide

## 1. Headings
Use `#` for the main heading, `##` for a section, and `###` for a subsection.

## 2. Emphasis
- `**bold**` becomes **bold**
- `*italic*` becomes *italic*
- `` `inline code` `` becomes `inline code`

## 3. Lists
Unordered:
- First item
- Second item

Ordered:
1. First step
2. Second step

## 4. Links and images
`[GitHub](https://github.com)` creates a link.

## 5. Code blocks
Use triple backticks and optionally specify a language:
```python
print("Hello, Markdown!")
```

## 6. Tables
| Command | Purpose |
|---|---|
| `git status` | Show working-tree state |
| `git log --oneline` | Show compact commit history |

## 7. Task lists
- [x] Create README
- [x] Add project overview
- [ ] Add future improvements
